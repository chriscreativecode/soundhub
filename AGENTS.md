# AGENTS.md

The project instructions live in [CLAUDE.md](./CLAUDE.md), whichever agent you
are: the commands, the architecture, the two sibling repositories that read this
one directly, the release process and the writing style. That file is the single
source of truth. Read it before changing anything here.

Two rules from it are worth repeating, because they are the ones that show up in
published output:

- No em dashes or en dashes in prose. Use a full stop, a comma, a colon or
  parentheses. Number ranges get the word "to".
- `README.md` ships to npm and is the first thing anyone reads, so every rewrite
  of it goes through the humanizer skill first, and gets checked for dashes
  before it is called done.
